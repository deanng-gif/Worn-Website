# Worn

Skip the hassle, see how it's Worn.

Landing page for Worn, an AI clothing try-on website (ENGR 310 project by Dean Nguyen).

## Files

- `index.html` - landing page
- `get-started.html` - Get Started page
- `styles.css` - shared styles (colors are set at the top under `:root`)
- `images/` - landing page photos

This is a plain static site: no build step is needed. Open `index.html` in a browser to preview it locally.
